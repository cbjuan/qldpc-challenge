# [[384,96,4]] — high-rate asymmetric-support periodic BB

## Direction & hypothesis

Search the periodic rectangular-torus bivariate-bicycle family for the
weight-8, unrestricted high-rate gap at `288 <= n <= 470`, aiming for
`k >= 52`. The campaign tracks `k^2*d/n` alongside the board's `k*d^2/n` and
promotes only candidates with a witnessed `d >= 3`. This candidate tests an
unequal 6+2 support profile produced by the shared-binomial-factor kernel,
rather than restricting the family to equal support sizes.

## What was searched

The first phase generated 20,000 deterministic broad proposals across the
periodic-BB lanes. Candidate 19513 uses an `8x24` torus with six terms in A,
two in B, and check weight 8. The structural census computed `k=96` and found
one Tanner component of size 384, so the code is indecomposable by that test.
It was packaged at 400 Python RIS trials and promoted through independently
seeded 8k, 60k, and 1M confirmation rungs.

Claim: **`d <= 4`, a witness-backed upper bound, not an exact distance.**
Literature novelty is unverified. This result is local-only and unsubmitted.

- Board FOM: `k*d^2/n = 96*4^2/384 = 4.0000`.

## Dead ends

No distance collapse occurred across the four-rung ladder. The asymmetric
6+2 support survived the structural and confirmation funnel, whereas exact
translated `A=B` proposals are skipped and witnessed `d=2` candidates are
kept only as audit results. A reconstruction of the known `[[288,50,8]]`
periodic BB code was rejected separately as an exact board duplicate.
