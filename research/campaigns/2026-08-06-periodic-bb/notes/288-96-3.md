# [[288,96,3]] — high-rate order-3 shared-factor periodic BB

## Direction & hypothesis

Re-mine the persisted periodic-BB structural ledger for codes that score well
under the campaign's additional `k^2*d/n` metric while still witnessing
`d >= 3`. Shared-binomial-factor proposals whose common factor has group order
three were prioritized after the earlier order-two examples collapsed to
distance two.

## What was searched

Candidate 16039 came from the breadth lane of the first 20,000-proposal
structural census. It is a connected weight-8 code on `Z_6 x Z_24` with 6+2
supports and the shared-binomial-factor kernel. It was recovered from the
stored ledger and persisted first at 400 Python witness trials, then promoted
through 8k and 60k confirmation rungs.

## Evidence trail

Both logical sides were witnessed at weight 3 in the saved 400-trial package.
The estimate remained 3 through an 8,000-trial Python plus 8,000-trial
accelerated rung and a final 8,000-trial Python plus 60,000-trial accelerated
rung. The final Python seed was 1102068388; the accelerated weight-3 X witness
used seed 1102068405 and passed the trusted Python GF(2) checks. Trusted
validation at seed 990757979 passed, found no lighter logical in its independent
8,000-trial pass, found no exact or WL board match, and labeled the code as
advancing weight-8 x unrestricted.

Claim: witness-backed `d <= 3`, not exact. Literature novelty unverified. The
candidate and all evidence remain local and unsubmitted.

FOMs: `k^2*d/n = 96^2*3/288 = 96.00`; `k*d^2/n = 96*9/288 = 3.00`.

## Dead ends

The campaign's order-two shared-factor calibrations produced `d=2`, which the
user excluded from useful correction-code leadership. This code clears that
floor, but it is locally dominated by the independently constructed
`[[288,100,3]]`, which has the same `n` and witnessed distance with four more
logical qubits. It remains useful evidence for the order-three search lane.
