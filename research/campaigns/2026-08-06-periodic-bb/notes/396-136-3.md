# [[396,136,3]] — high-rate weight-8 shared-factor periodic BB

## Direction & hypothesis

Search the periodic rectangular-torus bivariate-bicycle family for the
weight-8, unrestricted high-rate gap at `288 <= n <= 470`, aiming for
`k >= 52`. The campaign prioritizes `k^2*d/n` in addition to the board's
`k*d^2/n`, while requiring a witnessed `d >= 3` before promoting a candidate.
This candidate came from the shared-binomial-factor proposal kernel and has
the largest `k^2*d/n` among the campaign's validated local findings so far.

## What was searched

The first phase generated 20,000 deterministic broad proposals across the
periodic-BB lanes. Candidate 14474 uses a `6x33` torus with 4+4 supports and
check weight 8. The structural census computed `k=136` and found one Tanner
component of size 396, so the code is indecomposable by that test. It was
packaged at 400 Python RIS trials and promoted through independently seeded
8k, 60k, and 1M confirmation rungs.

The final candidate embeds weight-3 X and Z witnesses. Trusted validation at
seed 505592480 passed, independently found no lighter logical in 8,000 RIS
trials, found no exact or WL-equivalent board entry, and labeled the candidate
as advancing the weight-8 x unrestricted board.

Claim: **`d <= 3`, a witness-backed upper bound, not an exact distance.**
Literature novelty is unverified. This result is local-only and unsubmitted.

- Campaign priority: `k^2*d/n = 136^2*3/396 = 140.1212`.
- Board FOM: `k*d^2/n = 136*3^2/396 = 3.0909`.

## Dead ends

No distance collapse occurred across the four-rung ladder. The result's high
campaign score comes from its unusually large `k`; its distance and board FOM
remain modest. Elsewhere in the campaign, translated `A=B` proposals are
skipped structurally and witnessed `d=2` candidates are retained only for the
audit trail rather than promoted. A reconstruction of the known
`[[288,50,8]]` periodic BB code was also rejected as an exact board duplicate.
