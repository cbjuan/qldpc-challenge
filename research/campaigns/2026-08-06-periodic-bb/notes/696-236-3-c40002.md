# [[696,236,3]] — balanced order-3 BB continuation on Z_12 x Z_29

## Direction & hypothesis

Continue the validated order-3 shared-factor branch near the schema limit,
but replace the elongated `Z_6 x Z_58` geometry by a more balanced torus.
Preserving factor order 3 was expected to retain roughly one-third rate and
the parent's witnessed `d <= 3` branch while testing a structurally distinct
periodic BB code with the same `[[696,236,3]]` parameters.

## What was searched

A structural transfer audit generated connected, exact-k continuations with
`l*m <= 350` and no board-fingerprint duplicate. Candidate 40002 was
included in the six-record balanced order-3 promotion batch. It uses a
`12x29` torus, 4+4 supports, check weight 8, exact `k=236`, and one Tanner
component of size 696. It was screened at 400 Python RIS trials and promoted
through 8k, 60k, and 1M accelerated rungs.

## Evidence trail

The lightest witnessed logical stayed at weight 3 throughout:

- 400 Python trials, seed 685913362: `d <= 3`;
- 8,000 Python trials at seed 667534779 plus 8,000 accelerated trials at seed
  667534796: `d <= 3`;
- the persisted 8k Python result plus 60,000 fresh accelerated trials at seed
  1342168219: `d <= 3`;
- the same persisted 8k Python result plus 1,000,000 fresh accelerated trials
  at seed 1132323552: `d <= 3`.

The final candidate embeds weight-3 X and Z witnesses. Trusted validation at
seed 1094507980 passed, independently found no lighter logical in 8,000 RIS
trials, found no exact or WL-equivalent board entry, and labeled the candidate
as advancing the weight-8 x unrestricted board.

Claim: **`d <= 3`, a witness-backed upper bound, not an exact distance.**
Literature novelty is unverified. This result is local-only and unsubmitted.

- Campaign priority: `k^2*d/n = 236^2*3/696 = 240.0690`.
- Board FOM: `k*d^2/n = 236*3^2/696 = 3.0517`.

## Dead ends

No collapse occurred across the confirmation ladder, but the score gain is
rate-driven and the board FOM remains modest. The code shares parameters with
the `Z_6 x Z_58` continuation while using a different geometry and a different
exact stabilizer fingerprint; parameter equality was not treated as evidence
of equivalence. Lower-order factor mutations projected still higher campaign
scores but were retained as distance-collapse risks instead of replacing this
order-preserving candidate.

## Tools

Local structural transfer audit, deterministic periodic-BB campaign runner,
the repository BB/submission kit, `gf2_fast` with pair depth 16 and 8 threads,
trusted Python GF(2) witness checks, and the trusted local validator.

For the 60k and 1M rungs the runner reused the already persisted, schema-valid
8k Python candidate rather than repeating that expensive search. It required
exactly one source file, checked its n and k against the structural record,
recorded the source filename in provenance, saved each target under a new
non-overwriting path, and then persisted and Python-checked a fresh accelerated
witness. Thus reuse preserved the witness lineage without risking an in-memory
or print-only result. All artifacts remain local and unsubmitted.
